# PetGuardian API - Produto

PetGuardian e uma plataforma open source para conectar ONGs, lares temporarios, protetores e Pawdrinhos em torno do cuidado verificavel de animais em situacao de rua.

O backend deve sustentar perfis publicos de pets, apadrinhamento virtual, timeline, necessidades, doacoes rastreadas, cartinhas, denuncias, transparencia e memoriais.
