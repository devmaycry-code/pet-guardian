# UI Guidelines

## Direcao visual

- Acolhedora, calorosa e transparente.
- Evitar linguagem visual fria de fintech.
- Misturar blocos editoriais com cards claros e sinais de confianca.

## Paleta

- Creme claro para fundos principais.
- Laranja suave para CTAs.
- Verde esperanca para progresso e cuidado.
- Azul claro para verificacao e transparencia.
- Cinza neutro para apoio tipografico.

## Interacao

- Componentes grandes o suficiente para uso mobile.
- Busca e filtros sempre visiveis na listagem.
- CTAs claros, mas sem pressao emocional.
- Feedback imediato para login, apadrinhamento e denuncia.
